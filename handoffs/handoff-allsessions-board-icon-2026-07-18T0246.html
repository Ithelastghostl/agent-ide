Handoff — All Sessions board redesign + macOS icon fix

Date: 2026-07-18 · Repo: agent-ide · Branch: dev → merged to main

Scope

Two user-reported bugs: (1) the home "All Sessions" board controls (Live/Archived, Open Project, Sync history) were collapsed/unthemed with no proper section structure; (2) the macOS app icon didn't fit the icon grid and showed unwanted margins/border.

Root cause (the important part)

The board looked broken because of a pre-existing CSS syntax error: src/renderer/cockpit.css:974 had an unclosed .prompt-input { rule (missing }). A CSS parse error makes the browser silently drop every rule after it — which included the entire .allsessions board section. Result: browser-default white buttons stacked in a ~287px column. This was already on dev at HEAD (brace balance 422/421), so the redesign alone could not render until the brace was fixed. Fixing it restored 194 → 471 applied rules and also un-breaks other CSS after line 974 (modals, prompt inputs) app-wide.
