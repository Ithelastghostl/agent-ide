The three hard-gate fixes (consolidation)

  1. Harness on every launch path (gate 1). Three streams independently found the legacy session:launch bypassed launchService. composeLaunchPrimer is now the single canonical assembler (harness→agent→objective→history, with the R19/R22-3 fail-closed review-demotion), used by fresh/preset/queue launches AND resume/model-swap. The uniform harness — your core "every agent uses the same CLAUDE.md workflow" requirement — now injects on every provider launch. Anchored by a resume-injects-harness test + a fail-closed review test.
  2. Canonical CRLF fix (gate 2). S5 and S6 both independently hit a real latent bug: stripAnsi collapsed a CRLF-terminated prompt to empty (masking "needs input" as "idle", and erasing handoff text). Lifted into history.ts stripAnsi with a regression test; local patches now redundant.
  3. autoAdvance column (gate 3). Promoted S6's queue auto-advance flag from a JSON file to a projects.autoAdvance column (additive migration + Store get/set), so it's durable with the project row.
